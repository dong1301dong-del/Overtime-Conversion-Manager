## v1.0.1 — 鉴权漏判修复 + Navicat 兼容 + 验收自动化 — 2026-08-25

### 缺陷修复

| 编号 | 现象 | 根因 | 修复 | 影响 |
| --- | --- | --- | --- | --- |
| BUG-2026-08-25-01 | admin 登录后「修改密码」无响应（前端表现为弹窗不动，toast 偶尔闪「未登录」） | `WebConfig.addInterceptors` 一刀切 `.excludePathPatterns("/api/auth/**")`，导致 `AuthInterceptor` **根本没注册**到 `/api/auth/change-password` 与 `/api/auth/me`，因此 `CurrentUserHolder` 永远为空，`AuthService.changePassword()` 第一行就抛 `BizException("未登录")` | 将排除路径收窄为仅 `/api/auth/login`、`/api/auth/logout` 两个匿名端点 | 立即生效，已端到端复测（登录→改密→/me→还原→再登录 5/5 全码 0） |
| FIX-2026-08-25-02 | Navicat 连接 MySQL 报 `2059 - Authentication plugin 'caching_sha2_password' cannot be loaded` | MySQL 8 默认认证插件，老版 Navicat 不识别 | 1) `ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'root'`；2) 新建 Navicat 专用账号 `navicat / Navicat@1234`，权限限定在 `overtime_db` | 任选一种方式即可连接；应用 JDBC 不受影响（仍走 `allowPublicKeyRetrieval=true&useSSL=false`） |

### 交付

- **G6 自动验收脚本** `scripts/g6_probe.py`：覆盖 4 个角色 × 关键端点的权限矩阵，含未登录/伪造 token 负向用例。本轮修复后**42/42 全部 PASS**。
- **诊断脚本** `scripts/diag_token.py`：登录→DB token→`/me` 的快速三连比对，后续如再次出现「鉴权失效」问题可直接复跑。
- **迭代日志** `docs/迭代日志.md`（本文件）：作为后续变更的滚动笔记。
